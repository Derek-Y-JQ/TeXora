# TeXora 用户指南

> 适用于 TeXora 1.0（Windows）。本指南按「第一次打开 → 日常写作 → 进阶配置」的顺序组织。

---

## 1. 第一次启动

1. 启动 TeXora。窗口顶部显示当前项目，右侧为 PDF 预览区，左侧为文件树。
2. 点击左上角项目名 → **打开文件夹…**，选择一个包含 `main.tex` 的目录。
   TeXora 会自动寻找含 `\documentclass` 的主文档并在文件树中标记「主文档」。
3. 点击工具栏 **编译**（或 `Ctrl+Alt+B`）。首次编译会生成 `.latex_cache/`，PDF 渲染完成后显示在右侧。
4. 没有项目？点击 **模板中心**，选择模板并「创建项目」，TeXora 会生成主文档、参考文献与目录结构。

如果提示「未检测到 LaTeX 引擎」，请到 **设置 → 宏包与 TeX 环境** 指定 MiKTeX/TeX Live 的可执行文件目录。

---

## 2. 日常写作

### 2.1 编辑与补全
- 输入 `\begin{` 后出现环境候选；回车会补全 `\end{环境}`，光标停在中间并自动缩进。
- 输入 `\ref{`、`\cite{`、`\includegraphics{`、`\usepackage{` 会分别提示标签、文献键、图片与本地宏包。
- 在列表环境中按回车自动续写 `\item`；在空 `\item` 上回车退出列表。
- 输入片段前缀（`mk`、`ali`、`thm`、`fig`、`tab`…）后按 Tab 展开。
- 环境未闭合或名称拼错时，`\begin` 行会出现波浪线，悬浮查看说明。

### 2.2 Block 模式
悬停在独立段落或最外层环境上时：
- 左侧出现 **⋮⋮ 手柄**，按住拖动可上下重排；
- 右侧出现 **AI 快捷条**（润色 / 提问 / 翻译 / 自定义），按钮可在设置中增删；
- 选中任意源码后同样弹出操作条。

在 **设置 → 编辑器与交互** 可整体关闭 Block 模式或仅关闭拖拽。

### 2.3 预览
- **行间公式**：`equation/align/\[...\]` 下方自动插入渲染预览（设置可关闭）。
- **悬浮**：鼠标在公式、`\includegraphics`、`\ref`、`\cite`、`\begin{env}` 上停留约 0.3 秒显示卡片。
- **TikZ / 表格**：`tikzpicture`、`tabular/tblr/longtable` 局部渲染预览。
- **PDF**：工具栏可缩放、适合宽度、翻页、反色、刷新、外部打开；双击 PDF 内容反向定位源码。
- **Markdown**：打开 `.md` 文件时预览区显示渲染结果；工具栏「整理 → 工具 → Markdown 预览与导出」可另存 `.tex`。

### 2.4 编译与问题
- 状态栏左侧显示编译状态；点击可停止/重新编译。
- 编译失败会自动展开问题面板：错误/警告按文件与行号列出，点击跳转；「编译输出」页签显示完整日志。
- 缺少宏包时会询问是否安装（可在 **设置 → 宏包与 TeX 环境** 改为自动安装或仅提示）。
- 实时预览默认开启：停止输入约 0.9 秒后自动编译；可在状态栏或设置中关闭。

### 2.5 文件与历史
- 保存时按设置自动记录快照；**本地历史**面板按日期列出，可 Diff 对比或恢复。
- **Git** 面板在检测到 Git 后可用：分支、更改、暂存、提交、Pull/Push、最近提交。

## 3. 插入对象

| 对象 | 入口 | 说明 |
| --- | --- | --- |
| 图片 | 工具栏图片按钮 | 选择本地文件或粘贴剪贴板图片 → 自动保存到 `figures/` → 生成 figure 环境（宽度/位置/Caption/Label 可调） |
| 表格 | 工具栏表格按钮 | 三线表 / 普通表格 / longtable / Tabularray；网格编辑、行列增删、Excel/CSV 粘贴解析、实时 LaTeX 预览 |
| 数学符号 | Σ 按钮 | 八大分类 + 最近使用，点击插入 |
| 文献 | 书本按钮 | 引用选择器（多选）、`.bib` 卡片管理、DOI/arXiv 抓取 |
| 环境 | 代码按钮 | 数学/定理/浮动体/文本四类环境卡片 |
| 脚注 / 批注 | 整理 → 工具、AI 快捷条 | `\footnote`、`todonotes` 批注 |

## 4. 整理工具

- **一键整理格式**（工具栏「整理」或 `Ctrl+Alt+F`）
  - 规范 `\begin/\end` 层级缩进；
  - 合并同一自然段内被硬回车截断的行（保留空行分段）；
  - 维护「导言区 / 正文」分界注释线与章节分界注释块；
  - 压缩连续空行。
- **中英文标点智能替换**：把全角逗号/括号/句号等转成半角（或反向），自动跳过注释、`verbatim`、`\verb` 与宏参数中的命令，重点修复公式内误输的中文标点。
- **行内公式 `\displaystyle` 化**：对含分式、求和、积分等行内公式自动加 `\displaystyle`，并在导言区补充 `\linespread{1.15}` 行距补偿。
- **ChkTeX**：编译后按设置运行，结果进入问题面板。
- **latexdiff**：选择两个 `.tex` 生成带增删标记的对比 PDF（返修 Rebuttal 场景）。

## 5. AI 助手

1. **设置 → AI 助手**：选择服务商（DeepSeek / OpenAI / Claude / Gemini / Kimi / 自定义），填写 Base URL、API Key、模型名，点击「测试连接」。
2. 常用入口：
   - Block 右上角快捷条：润色 / 提问 / 翻译 / 自定义；
   - 选中源码 → 浮动条；
   - 左侧 AI 面板：解释、润色、互译、生成表格、自由提问；
   - 问题面板「AI 修复建议」：结合日志与源码诊断；
   - 剪贴板截图 → 「截图转 LaTeX」。
3. 生成结果以 **Diff 卡片**呈现：可复制、插入到下方、替换原文或重新生成。AI **不会**自行保存或修改文件。
4. **上下文范围**：仅选区 / 当前文件 / 文件+导言区 / 全项目；可开关跨文件读取与导言区宏携带。
5. **Skills**：导入 Markdown/TXT 规则（期刊规范、个人宏习惯），启用后会拼接到系统提示词。

> 密钥保存在 `%APPDATA%\TeXora\settings.json`，仅在主进程中使用，不会注入页面。

## 7. 排错

| 现象 | 处理 |
| --- | --- |
| 编译按钮无反应 / 提示未检测到引擎 | 设置 → 宏包与 TeX 环境 → 填写 MiKTeX 或 TeX Live 的 `bin` 目录 → 检测 TeX 环境 |
| 中文乱码或字体缺失 | 使用 `xelatex` + `ctex` 文档类；在字体选择器中指定本地中文字体 |
| PDF 预览空白但编译成功 | 检查 `pdftoppm`/`pdftocairo` 是否可用（设置 → 关于与环境） |
| 双击 PDF 无法反向定位 | 确认编译参数包含 `-synctex=1`（TeXora 默认添加），并清除缓存后重编 |
| 环境名误报未知 | 在导言区用 `\newtheorem` / `\newenvironment` 定义后重新解析 |
| 宏包安装失败 | 切换 CTAN 镜像；TeX Live 可能需要管理员权限或 `--usermode` |
| AI 请求失败 | 检查 Key、Base URL 与模型名；403/429 分别代表权限/额度问题 |
