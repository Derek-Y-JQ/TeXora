# 文件、PDF 与外部工具工作流

## 从文件夹进入

在 Windows 中将 `.tex` / `.ltx` 的打开方式设为 TeXora，双击后打开指定文件。程序已经运行时，文件交给现有窗口处理；切换项目遇到未保存内容会先提示保存。中文、空格路径均受支持。

直接双击主文件时使用该文件编译。子文件优先读取 `% !TeX root = ../main.tex`；没有指令时寻找附近目录的常见主文档。可在状态栏调整主文档。

安装后，文件夹及文件夹空白处的右键菜单提供“用 TeXora 打开”（Windows 11 可能位于“显示更多选项”）。也可以拖入文件夹或文件，使用 Ctrl+O 打开文件夹、Ctrl+Shift+O 打开文档 / PDF。

## 阅读 PDF

点击预览栏的打开按钮，或从文件树、文件对话框及系统打开方式载入 `.pdf`。文件以只读方式阅读，不改写 PDF；打开独立 PDF 不切换已有源码项目。

全文预览直接解析原始 PDF，以 PDF.js 在当前缩放与屏幕密度下重绘，并叠加可选择复制的文字层。它不再先把整本书转换为固定分辨率 PNG。离线字体、CMap 与解码器随安装包分发。原文件本身为扫描图片时，不会自动生成 OCR 文字。

同一主文档编译后保留浏览页、页内相对位置、水平位置及缩放；页数减少时落在有效范围内。当前编译 PDF 保留 SyncTeX；独立 PDF 只有与当前项目的有效编译结果及跟踪文件相匹配时才启用定位，避免跳到错误源码。

预览栏显示来源与时间。编译失败或中断时保留可读的上一份成功结果，并明确标记；失败会展开原始日志末尾。加密 PDF 会提示使用外部阅读器。

## 文件级 Agent 协作

外部工具可直接编辑项目内的 `.tex`、`.bib` 等文本；TeXora 会检测磁盘变更。未保存的编辑器内容不被外部修改静默覆盖。

无需操纵鼠标即可打开或编译：

```powershell
& 'C:\Program Files\TeXora\TeXora.exe' --project='D:\论文项目'
& 'C:\Program Files\TeXora\TeXora.exe' --open='D:\论文项目\chapters\绪论.tex'
& 'C:\Program Files\TeXora\TeXora.exe' --build --project='D:\论文项目\main.tex' --engine=xelatex
```

请替换为实际安装路径。`--build` 不打开工作台，读取磁盘上的源码，沿用 TeX 设置与编译流程，输出包含 `ok`、PDF 路径、问题与日志末尾的 JSON；成功退出码为 0，失败为 1，缺少项目参数为 2。它不会替编辑器保存尚未落盘的内容，也不改变最近项目。

## AI 与整理

AI 回答完整保存在本地历史，侧栏和详情支持 Markdown 阅读、复制、追问与继续。历史改写建议关闭后仍能重新打开差异并应用；原文变化时重新核验目标，已应用的结果不会重复写入。模型因输出上限中断时明确提示，继续回答会携带前文。历史不会保存原始截图或服务密钥。

整理源码支持当前选区或整个文件，先展示差异，确认应用后可撤销。清理编译产物先列出待删除项目与空间占用；与重新编译分开操作。
