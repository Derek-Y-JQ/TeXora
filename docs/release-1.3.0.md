# TeXora 1.3.0

## 界面与交互

- 区分章节、行距、数学符号、公式显示、插入环境、自动编译和 AI 助手的按钮图标；统一加粗线条及圆角细节。
- 优化编译主按钮：编译时可直接点击停止，停止过程中显示反馈，完成后恢复编译操作；编译选项下拉菜单与引擎菜单分开。
- 再次点击左侧当前面板图标即可收起侧栏；再点展开，点击其他图标切换到对应面板。
- 编辑区右上角新增高亮主题菜单：跟随日夜、One Dark、GitHub Dark、Monokai、Solarized Light、GitHub Light、One Light、Quiet Light。选择立即生效并持久保存，不改变应用日夜主题。

## 编辑与编译修复

- 编译前保存已修改的打开文件，避免编译旧内容；修复编译状态不同步与重复触发。
- 修复停止编译后仍继续执行后续遍数的问题；停止不会再被误报为普通编译失败。
- 标点转换保留公式、跨行数学环境、代码、注释、命令标识、引用、路径、URL、邮箱、小数和英文句子，保留顿号与引号。
- 修复自动换行宽度、Block 首次悬浮及滚轮悬浮高亮；将 Block AI 按钮移到正文外侧竖栏。

## 安装

保存文档并退出旧版，运行 **TeXora-Setup-1.3.0.exe**。安装完成后在「关于 TeXora」中确认版本为 **1.3.0**。

提供安装包、自动更新元数据、blockmap 与 SHA-256 校验文件。安装包尚未进行代码签名。
