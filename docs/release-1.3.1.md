# TeXora 1.3.1

## 整理原稿

- 修复 `\[ ... \]` 公式后的正文被合并到闭合符号同一行的问题。
- 数学与代码区域保留原始行结构，保留公式内部空行、行尾注释和独立注释；修正转义百分号的判断。

## AI 助手

- 删除侧栏的「解释」「润色」「互译」「表格代码」四个快捷按钮。
- 历史消息完整保存到本地，点击可重新打开。未应用的建议继续显示 Diff；已替换或插入的建议只显示应用后的内容，并标记「已修改」，避免重复应用。
- 默认 DeepSeek 模型改为 **deepseek-flash**。原官方默认 deepseek-chat 配置迁移一次；自定义模型与后来手动选择的模型保留。
- 在输入框上方提供 **2×2** 控件：选中内容、当前文件、Skills、其他文件。
- Skills 可直接多选本次需要的规则；其他文件可多选项目中的文本文件（最多 8 个）。所选上下文和规则放在手写指令前面。

## 上下文范围

侧栏和 Block 共用同一个上下文构建器：设置中的范围是读取上限；侧栏按钮可以取消本次不需要的内容。

- **仅选中内容 / Block**：不回退读取全文，也不额外读取主文档或其他文件。
- **当前文件**：可把当前文件作为参考；Block 的原始内容依然是实际修改目标。
- **当前文件 + 主文档导言区**：开启相应选项时，处理子文件会补充主文档宏与宏包。
- **项目范围**：还需开启「允许跨文件读取」，才可手动选择其他文件。不会自动发送整个项目。
- Skills 是本次规则选择，不会因为选择某个文件就自动附带其他规则。

## 稳定性修复

- AI 建议绑定发起时的原文件和目标范围，切换文件不会把建议写进其他文档。
- 应用前检查原文；原文已变化或匹配不唯一时拒绝覆盖，不再静默改为光标插入。
- 历史记录的重新生成使用该条记录自身的请求，避免使用后来请求的内容。
- 支持取消请求，抑制重复发送；失败时保留手写指令并清理等待消息。
- 空回复、服务错误与输出截断均可恢复；截断内容仅预览，不能直接应用。
- 修复多选菜单外部关闭及反复打开弹窗时残留的键盘监听。

## 验证与安装

通过格式整理、上下文权限、模型迁移、历史恢复及 AI 服务单元测试；使用本地模拟 AI 服务验证界面流程，不消耗真实模型额度，并实际编译整理后的含行间公式文档。

保存文档并退出旧版后运行 **TeXora-Setup-1.3.1.exe**，在「关于 TeXora」中确认版本为 **1.3.1**。
