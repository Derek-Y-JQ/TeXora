# TeXora 1.3.3

- 新增代码块编辑弹窗：listings / minted、语言、行号、标题与标签；自动检测、安装缺失依赖并实际试编译。
- 新增伪代码编辑弹窗：循环、分支、函数、过程、输入输出、返回值和注释组件；插入时去重补齐主文档宏包。
- 更新全局 AI 提示词，支持通用问答、数学检查与纠错、双向翻译等任务；四个默认动作为润色、检查、翻译、解释。
- 检查与解释默认作为回答，改写与翻译使用 Diff；新增提示词恢复默认按钮，保留自定义提示词。
- Block AI 悬浮提示改为动作名称；默认夜间蓝色，新增茶绿、晴空、日晷配色。
- 修复并发预览缓存探针冲突及 SyncTeX 定位缓存误切换。
- README 以功能列表与本版本实际截图介绍工作台，并移除旧版更新记录。

已通过自动回归、本机依赖检测安装、listings / minted / 算法完整 PDF 编译、AI 模拟服务、预览及 SyncTeX 双向定位检查。

minted 首次配置需要网络及可用的包管理工具；网络或权限失败时保留编辑内容、显示原因，可改用 listings。自动配置仅为当前项目启用所需外部程序调用。
