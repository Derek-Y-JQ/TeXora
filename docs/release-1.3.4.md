# TeXora 1.3.4

- 点击 Block 右侧 AI 动作后立即展开 AI 助手侧栏，定位到最新请求与消息；修正滚动目标，折叠侧栏时也能正常跳转。
- 润色、翻译等改写任务增加替换正文格式约束与解包检查；Diff 只接收提取后的文稿，无法可靠分离的说明或多个代码块会提示重新生成，不修改文件。
- 移除默认润色提示词“另附问题说明”的冲突要求，仅更新旧默认提示词，保留用户自定义内容。检查与解释仍使用独立回答。
- 数学环境、标签与引用新增“本文件 / 整个项目”标签页，范围选择独立保存；支持未保存编辑、来源文件显示、跨文件定位与自定义定理类型。
- 当前文件中的引用按整个项目检查目标，避免正常跨文件引用被误报；读取失败时明确提示结果不完整。

已通过自动回归、本地模拟 AI 界面测试、标签页快速切换与重启恢复、跨文件导航、未保存索引及超过 60 个文件的项目索引检查。
