# TeXora 1.4.0

本次更新重点改善文件保存可靠性、搜索替换和键盘操作。

- 保存按文件排队，防止重叠写入；保存期间的新输入继续显示为未保存。
- 批量保存失败不再提示全部成功；切换项目前可保存全部修改，关闭项目会检查所有标签页。
- 关闭窗口或重新载入时，对未保存的内容显示确认提醒；安装程序不再提前强制结束编辑器。
- 项目替换遵守整词匹配，普通替换保留 `$` 等字面内容；有未保存文件时先提示保存。
- 零宽正则搜索正确前进；清空搜索立即移除旧结果，较早的请求不会覆盖新结果。
- 搜索高亮先匹配原文再转义，避免尖括号、实体符号导致高亮错误。
- 修复相对路径解析，创建文件、目录、图片及重命名拒绝越过目标目录。
- 切换项目后清除旧文件监视计时器，关闭文件后清除自动保存计时器。
- 修复同一回调多次订阅事件时无法独立取消的问题。
- 弹窗替换会结束原来的等待操作并释放资源；增加对话框语义、Tab 焦点循环、焦点恢复及窄窗口布局。

## 验证

保留原有回归测试，新增保存并发、保存失败、整词替换、零宽搜索、文件路径和计时器回归测试。界面测试覆盖弹窗替换、键盘焦点、非当前标签页未保存提醒、搜索和清空结果。

## 安装

下载 `TeXora-Setup-1.4.0.exe`，关闭旧版后安装。LaTeX 编译仍需要本机 TeX 环境；Overleaf 和 AI 功能需要相应账号及网络。
