# TeXora 1.4.1

修复 PDF 在外部阅读器中文正常、TeXora 内部预览却缺少中文的问题。

- 识别 Poppler 返回成功状态时仍输出的中文映射、字体和字形异常，包括 `Missing language pack for Adobe-GB1`、`Unknown font tag` 和 `No font in show/space`。
- 出现异常时自动尝试备用 Poppler 渲染器，必要时使用本机已有的 Ghostscript / MiKTeX mgs；全文 PDF 和公式、表格等局部预览使用相同的后备逻辑。
- 长文档先渲染第一页检查兼容性，避免用已知异常的渲染器反复处理整本文档。
- 各次尝试使用独立目录，拒绝损坏或失败尝试遗留的页面；异常结果不写入正常预览缓存。
- 预览缓存加入渲染逻辑版本、工具和字体映射环境信息；升级后不再复用旧版缺字缓存。
- 所有渲染器失败时显示明确的预览失败说明，保留生成的 PDF 供外部打开。

## 验证

通过现有回归测试、新增 PDF 字体异常和缓存失效测试、两页中文实际编译与双引擎渲染验证。使用实际故障文档验证中文映射异常检测和自动切换，抽查封面、正文及末页。用户文稿、PDF 和项目内容不随应用发布。

## 安装

下载 `TeXora-Setup-1.4.1.exe`，保存文档并关闭旧版后安装。重新打开项目后会生成新的预览缓存。

备用 Ghostscript 使用本机已有工具，不另行捆绑；如 Poppler 缺少中文映射且本机没有可用的备用渲染器，需补齐 TeX 环境或使用外部阅读器。
