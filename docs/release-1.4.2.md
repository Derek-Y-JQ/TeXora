# TeXora 1.4.2

修复 Overleaf 网页可编辑、TeXora 却提示只读而无法上传的问题。

- 使用当前 Overleaf 项目列表接口及网页验证信息读取项目权限；接口不可用（404/405）时兼容旧版项目列表。
- 兼容 accessLevel 和 privilegeLevel 权限字段，正确识别所有者与可编辑协作者。
- 将未识别的权限单独显示，提示刷新项目或重新登录，避免误报“只有读取权限”。
- 同步执行前重新检查权限，真正只读、权限已撤销或尚未识别的账号仍不能写入云端。
- 保留 1.4.1 的 PDF 中文渲染修复。

## 验证

覆盖现代接口、旧版回退、所有者、可编辑协作者、只读、未知权限及登录失效的自动测试；检查发布安装包及同步确认界面。验证不修改用户的 Overleaf 项目，实际账号回传仍需在安装后确认文件变更并执行。

## 安装

下载 `TeXora-Setup-1.4.2.exe`，保存文档并关闭旧版后安装。打开 Overleaf 面板点击“刷新项目”，然后重新检查同步；若提示登录失效，请重新登录。
