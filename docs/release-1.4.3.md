# TeXora 1.4.3

根据使用反馈改善文件入口、PDF 阅读、编译诊断与 AI 回答复用。

## 同版本修复 · 2026-10-30

此安装包根据诊断反馈重新构建，应用版本仍为 **1.4.3**。已安装首发 1.4.3 的用户需重新下载安装包并覆盖安装，版本检查不会把同版本当成新版本。

- 环境检查按当前发行版与功能判断：TeX Live / TinyTeX 使用 tlmgr，MiKTeX 使用 mpm；辅助工具缺失不再误报编译环境损坏。
- 修复 Windows 无法直接启动 tlmgr.bat 的调用问题；避免借用其他发行版的包管理器。
- “仅提示不安装”对两种管理器均生效；切换发行版及装包成功后刷新包名、样式文件和版本缓存，失败查询不再缓存一天。
- 修复新版 MiKTeX 列表的状态列被误识别为包名，只展示已安装的真实宏包名。
- Markdown 纸面使用独立配色；六级标题、引用、代码、链接与表格在昼夜主题下均清晰可读，界面内的 Markdown 保持主题配色。
- 修复设置窗口已关闭时，异步环境检查刷新界面引发的异常。

新增多发行版模拟与 Windows 批处理实测；昼夜与四种强调色下的 Markdown 对比度检查，最小值 6.20:1。保留首发 1.4.3 的功能与回归检查。

## 1.4.3 首发功能

- 修复设为默认编辑器后双击 TeX 文件却恢复上次项目的问题；支持冷启动及已运行窗口，正确载入目标文件、主文档与目录。
- 新增文件夹右键“用 TeXora 打开”、文件 / 文件夹拖入，以及文档与 PDF 打开入口；兼容中文和空格路径、TeX root 指令。
- 全文预览改为直接读取原始 PDF，使用离线 PDF.js 按缩放与屏幕密度重新绘制，并提供文字选择、复制、链接和夜间模式。仅渲染视口附近页面，释放远处页面画布。
- 重编译保留当前页、页内位置、水平位置和缩放，避免回到第一页。PDF 使用独立的不可变快照，避免覆盖正在阅读的文件。
- 独立打开 PDF 只读阅读，不切换源码项目；匹配当前项目的有效 PDF 保留 SyncTeX 定位。
- 失败必有错误诊断与原始日志末尾，区分成功、失败和停止；保留旧 PDF 时标明来源状态与时间。
- 加粗、斜体、下划线、等宽和强调支持再次点击取消、嵌套内容、光标状态高亮及撤销。
- AI 侧栏完整渲染 Markdown，移除 420 字截断和静默历史条数裁剪；支持历史回答追问、继续、改编，继续时带上前文。未应用的建议可稍后重新打开应用。
- 整理前展示差异，可只整理选区并撤销；清理前显示待删项目与占用空间，阻止清理源码目录或正在编译的文件。
- 新增无需 GUI 操作的命令行编译与 JSON 结果，便于 Agent 直接读写源码并验证。
- 修复目录解析把 includegraphics 误识别为 include；为 Windows 短暂占用下的 AI / Overleaf 状态文件替换增加重试。

## 验证

现有回归与新增入口 / 格式 / 历史测试；实际 XeLaTeX 多页编译与重编译位置保持；真实失败诊断；独立 PDF 文字层和缩放重绘；冷 / 热启动文件传递；中文 PDF；SyncTeX 正反定位和跨项目过期结果保护。AI 追问测试使用隔离的模拟响应，不发送用户稿件至模型服务。

## 安装

保存文档并关闭旧版，安装 `TeXora-Setup-1.4.3.exe`。文件夹右键入口由安装器注册；若系统打开方式仍指向旧路径，请重新选择新版 TeXora。既有设置、项目与历史保留。

更多操作见[文件与命令行工作流](file-workflow.md)。
