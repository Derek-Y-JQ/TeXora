# TeXora 1.5.1

## 界面

- 界面图标整体换为 Lucide（ISC 许可）单色线条，尺寸统一为 12 / 14 / 16 / 18 px 四档；`\emph`、`\texttt` 与标点转换使用自绘字形。
- 文件树、标签页与模板文件列表按类型显示不同图标：tex、bib、sty、cls、md、pdf、图片、数据、日志等。
- 全新应用图标；欢迎页的标志同步为应用图标。
- 工具栏：“图片”“表格”带文字；标点转换改为“中→英 / 英→中”；删除线、`\displaystyle` 化、自动换行移入“更多”菜单，命令与快捷键不变。
- 悬停提示改为自绘样式并单独显示快捷键；纯图标按钮补充无障碍名称；浅色主题的次级文字对比度提高到 4.5:1 以上；状态栏在有错误或警告时才着色。

## 本地化

- 新增 English 与日本語界面，在“设置 → 外观与主题 → 界面语言”切换，立即生效，原生菜单与系统对话框同步切换。
- 译文覆盖约 1700 条界面文字。未收录的文字会保留中文显示；文档内容、文件名、模板正文与 AI 提示词不翻译。

## 修复

- 字号：对已设字号的选区再次选择同一字号会取消；选择其他字号会替换，不再嵌套。
- 菜单或弹出面板展开时，点击标题栏空白处可以收起；窗口失去焦点时也会收起。

## 安装与签名

Windows x64 安装包保留用户数据。当前发行未签名。

## 验证

`npm test` 新增界面语言测试（词条占位符一致性与匹配规则）。本次改动在 Windows 开发窗口中做过界面检查；本地化与新应用图标为本版新增，如发现漏译或显示问题请在 Issues 反馈。
