# TeXora 2.0.0

## 编译与缓存

- 检测 `putenv(TEXMF_OUTPUT_DIRECTORY=...)` 致命错误后，自动改用可写的 ASCII 缓存目录重试一次。保留项目工作目录，源文件、图片与子文件路径无需更改。
- 恢复成功后继续后续编译遍次及参考文献步骤，不把已恢复的首次失败计为最终失败。普通 LaTeX 错误不触发缓存切换；停止编译不会继续重试。
- 支持绝对缓存目录；英文缓存中的 PDF 可重新打开并关联匹配的 SyncTeX，项目旁的 PDF 同步继续生效。没有可写 ASCII 缓存时给出明确提示。

## 窗口和工具栏

- 窗口改变大小、最大化/还原、分栏拖动与复位共用视口宽度限制，重新调整编辑器与 PDF 页面。
- 监听 PDF 容器实际尺寸变化，重排后刷新页面渲染；窄分栏下的 PDF 工具条可横向滚动。
- AI 助手移至常驻工具栏尾部；格式工具保留可见横向滚动条并支持鼠标滚轮横向滚动。
- 最小窗口宽度调整为 900，保留原有菜单、快捷键、主题和本地化。

## 安装与签名

Windows x64 安装包保留现有用户数据。当前发行未签名。

## 验证

新增缓存错误回退、再次编译/重新打开、绝对路径、普通错误、取消、latexmk 和分栏宽度回归。发布前执行正式回归、构建及打包窗口检查。

本机 TeX Live 2025 的最小“第1题”项目可正常编译，未自然触发同一 fatal。另以首次 fatal 故障注入配合后续真实 XeLaTeX 编译，验证英文缓存恢复、PDF 输出和 SyncTeX；原生窗口最大化/还原、1440→900→1440 缩放、AI 按钮可见可点及横向滚动回归均通过。
