# TeXora 2.0.1

## Endfield 样式修复

- 与 Studio 的蓝色、紫色、茶绿、晴空、Solarized 等强调色及配套底色隔离；切回 Studio 会恢复原来的选择。Endfield 设置页只显示自身配色选项。
- 青蓝色 `#14D0D0` 与柔黄色统一由一处定义。桌面主要按钮使用墨底，悬浮和键盘焦点使用当前配色；编译中使用浅底与斜线纹，不再回退为黄色或红色。选中文件、导航、主题采用柔和浅底。
- 清理设置、菜单、弹窗、侧栏、工具栏、开关及编辑器候选栏的硬编码圆角、柔和阴影、装饰渐变和模糊背景；可点击控件使用切角，正文容器使用直角。
- 编辑器候选栏、搜索、选区、匹配框等界面颜色跟随 Endfield；独立选择的代码语法高亮主题继续保留。
- 主题预览使用当前强调色与中性灰；非删除类错误提示改用浅色旗标和清晰文字，保留可见键盘焦点与减少动效设置。Saira 字体及已有许可证随应用提供。

## 自动补全修复

- `\b`、`\be`、`\beg`、`\begi`、`\begin` 接受默认补全时只插入 `\begin{}`，光标位于括号内，并提供环境候选；不再默认插入 `equation`。
- 隔离文件树样式对候选栏的影响，修复单项和末项被裁切。

## 验证与安装

增加正式界面回归：明暗 × 青蓝/柔黄、8 种 Studio 配色隔离、真实鼠标悬浮、常用弹窗、候选栏、键盘焦点、900px 窗口、200% 放大、减少动效及切回 Studio。随 CI 执行。

Windows x64 安装包保留现有用户数据，当前发行未签名。
