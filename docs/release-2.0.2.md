# TeXora 2.0.2

- 修复新建环境后撤销又自动补回结束标记的问题。环境候选补全及其生成的结束标记作为一次撤销操作，后续正文输入独立撤销；撤销和重做不会触发新补全，也不会丢失重做记录。
- 显式回车支持自定义环境、尚未索引的环境以及带参数的环境。支持 `newenvironment`、`renewenvironment`、`newtheorem` 和 New/Renew/Provide/DeclareDocumentEnvironment 等定义，兼容空白、跨行及其他已打开文件中尚未保存的定义。完整环境名与候选相同时，回车也会生成结束标记；已有结束标记不会重复插入。
- 将“当前编译 PDF＋时间”移到右下角状态栏，时间只显示时、分；删除右下角 Git 图标和日夜切换入口。保留顶部日夜按钮及 Git 侧栏功能。
- PDF 工具栏下沿与左侧标签栏下沿对齐；窄窗下优先保留 PDF 状态，长名称可查看提示。

- 重新设计 Endfield 界面样式：顶部深色命令栏与三色条，侧栏、标签页和 PDF 栏以细线分区；当前面板、当前设置页使用主题色色块，主要按钮在鼠标悬停时由主题色从左擦入，编译中显示主题色斜线纹；提示与错误使用主题色标记，红色只用于删除。主题色改为标准黄、青柠、冰蓝、琥珀四种，可在“设置 → 外观与主题”中以色块选择；2.0.1 保存的青蓝色自动改为冰蓝。

- 环境补全只在按回车时插入 `\end{…}`：完整输入环境名、用 Tab 或鼠标接受候选都不再自动闭合。
- 新增 PDF 全屏阅读（Shift+F11）与演示模式（Shift+F5，从当前页开始）。演示时逐页铺满屏幕，方向键 / 空格 / 滚轮 / 点击翻页，Home / End 到首末页，数字加回车跳页，Esc 退出并回到停下的那一页。
- 数学符号面板改用 KaTeX 排版，符号平铺不再逐个加框；悬停显示 LaTeX 代码，底部同步显示当前符号与代码。
- 欢迎页的最近项目可单独移除（只从列表中去掉，不动磁盘上的文件）；关闭项目后欢迎页会显示最近列表。
- 启动时默认显示欢迎页，不再自动打开上次的项目；需要时可在“设置 → 文件”中重新开启。
- 删除编译组里与编译下拉菜单重复的引擎选择按钮，引擎在编译下拉菜单中切换。
- Endfield：编译与下拉按钮间距加大；去掉 PDF 工具栏左上角的黑条；主题色擦入时覆盖按钮边框，不再残留黑 / 灰边框，静止时也不再露出主题色细边；键盘焦点改为底边色条；白天模式顶栏改为白底；顶部三色条在启动时从左到右展开；编译中的斜线纹持续移动。动效在“减少动效”下关闭。

验证覆盖真实按键的撤销/重做、补全计时器取消、自定义环境候选、跨文件定义、已有结束标记及窄窗状态栏；Endfield 回归覆盖明暗 × 四种主题色。

Windows x64 安装包保留现有用户数据，当前发行未签名。
