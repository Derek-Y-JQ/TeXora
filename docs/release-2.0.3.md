# TeXora 2.0.3

- 环境补全只在按回车时插入 `\end{…}`；完整输入环境名、用 Tab 或鼠标接受候选都不再自动闭合。
- 新增 PDF 全屏阅读（Shift+F11）与演示模式（Shift+F5，从当前页开始）。支持方向键、空格、滚轮和点击翻页，Home / End 到首末页，数字加回车跳页；Esc 退出并回到停下的那一页。
- 数学符号面板使用 KaTeX 排版，符号平铺展示；悬停显示 LaTeX 代码，底部同步显示当前符号与代码。
- 欢迎页的最近项目可单独移除，只调整列表，不删除磁盘文件；关闭项目后显示最近列表。启动时默认显示欢迎页，可在“设置 → 文件”中重新开启自动打开上次项目。
- 删除编译组里重复的引擎按钮，通过编译下拉菜单切换引擎。
- 完善 Endfield 细节：增大编译与下拉按钮间距，去掉 PDF 工具栏左上角黑条，修正主题色擦入时的残留边框，键盘焦点改为底边色条，白天顶栏使用白底。
- 顶部三色条启动时从左到右展开，编译中的斜线纹持续移动；开启减少动效时关闭这些动画。

Windows x64 安装包保留现有用户数据，当前发行未签名。
